CAN      : CAN1 1 Mbps (Prescaler=4, 1+6+2 tq @ APB1 36MHz), LOOPBACK mode,
           accept-all filter (Bank0, 32-bit mask, mask=0) on RX FIFO0,
           RX0 pending interrupt -> HAL_CAN_RxFifo0MsgPendingCallback
Evidence : raw capture from COM8 (CH340 USB-TTL on PA9), 921600 baud, 6 s window

Interpretation:
- TX count increments once per 500 ms loop tick.
- RX count is exactly one behind TX (the frame sent this tick is received within
  the same tick; the printed RX block is the previous frame).
- Received payload bytes [0..1] carry a big-endian frame counter: RX #31 carries
  0x001F=31, RX #43 carries 0x002B=43 -> every frame's payload matches its RX
  sequence number, proving the full chain: AddTxMessage -> bxCAN loopback ->
  accept-all filter -> FIFO0 interrupt -> GetRxMessage.
